# 上下文约束

本文补充 `Lexical Structure`。本文只定义**合法性约束**：它们依赖标签的外围结构、同一标签内已出现的名称，或标签类型的声明，无法仅由上下文无关文法表达。

属性值如何产生、标签如何作用于文本、处理实例的生命周期与执行顺序，见 `Semantics.md`。

## 术语

- **标签类型（type）**：`block-start` 或 `single-markup` 中的 `type`。
- **属性契约**：标签类型在其 `Attribute` 声明中定义的属性集合、数据类型、默认值及是否必须注入。
- **函数契约**：标签类型为某个 `func` 声明的参数集合、数据类型、默认值及是否必须注入。

## 约束

### C1. 块标签匹配

对每个**显式闭合**的块 `B`，其结束标签的 `type` 必须与开始标签的 `type` 完全相同。

形式化表示：

    type(B.start) = type(B.end)

```html
<foo>...</foo>  <!-- 合法 -->
<foo>...</bar>  <!-- 非法 -->
```

根层级不得出现可直接闭合的结束标签。结束标签失配、孤立结束标签及缺少结束标签均属于结构错误；其 HTML 风格栈式恢复（隐式关闭或忽略孤立结束标签）见 `Error Handling.md` 的 E5。

### C2. 属性名唯一性

同一个 `prop-list` 中，同一参数名不得出现超过一次。

```html
<effect : speed = 1, speed = 2>text</effect>  <!-- 非法 -->
```

重复属性必须判为解析失败；不得使用“后者覆盖前者”解释同一标签内的重复属性。

### C3. 块标签的属性契约

每个标签类型必须通过 `Attribute` 声明其可接受的属性。标签中的每个属性名必须存在于该标签类型的属性契约中；未声明的属性必须判为解析失败。

属性值必须符合契约声明的数据类型；标签实现可附加值域、枚举、非空或跨属性关系等语义校验。校验不通过时，该标签必须判为解析失败。

标注 `allowDefault = false` 的属性必须在当前标签中显式填写，且不能填写默认值：字符串为 `""`，整数和浮点数为 `0`，布尔值为 `false`。省略或显式填写默认值均为契约错误。

```html
<wave : speed = 2>...</wave>       <!-- speed 已由 wave 声明 -->
<wave : unknown = 1>...</wave>     <!-- 非法：unknown 未声明 -->
```

### C4. 单标记函数契约

单标记中的 `func` 必须由对应 `type` 的 `Attribute` 声明。具名形式中，每个参数名必须存在于该函数契约中，且参数名不得重复。

单值形式只在函数契约**恰有一个参数**时合法；该值绑定到该唯一参数，并按其数据类型和实现校验。参数数量为零或多于一个时，单值形式没有可确定的绑定目标，必须判为解析失败。

标注 `allowDefault = false` 的参数必须显式填写非默认值；此约束同时适用于具名形式和单值形式，默认值定义同 C3。

```html
<pause:wait(0.35)>                 <!-- 合法：wait 仅声明 duration -->
<pause:wait(duration:0.35)>        <!-- 合法：具名形式 -->
<audio:play("ui_warning")>         <!-- 非法：play 声明多个参数 -->
```

未知 `func`、未知参数、重复参数、单值形式不能唯一绑定、参数类型不匹配或未通过函数实现校验时，该单标记必须判为解析失败。

### C5. 标识符比较

`type`、`func` 和 `param` 必须使用 `Lexical Structure` 的 `name` 产生式，并按字符完全相等进行比较。标识符不得进行大小写转换；不符合 `name` 的标识符必须解析失败。
