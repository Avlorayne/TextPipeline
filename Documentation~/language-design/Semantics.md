# 语义

本文定义语法合法的标记文本在解析成功后如何形成属性值、处理实例与正式文本。语法形式见 `Lexical Structure`；合法性判定见 `Contextual Constraints.md`。

## 术语

- **处理实例**：负责某一标签类型效果与生命周期的运行时对象。
- **有效属性值**：某个标签位置实际使用的属性值。
- **实例键**：处理实例的唯一标识，记为 `(type, scope)`。
- **正式文本**：解析完成、已收束所有成功标签字符后，交给后续处理的文本。

## 语义规则

### S1. 属性值形成

属性契约与函数契约分别定义属性/参数的数据类型、默认值及是否必须注入。一个属性或函数参数的有效值按以下优先级形成：

1. 当前标签显式填写的值；
2. 同一处理实例的外层标签有效值；
3. 契约声明的默认值。

标为“必须注入”的属性或参数，在形成有效值后必须注入对应标签或函数实例；它的值可来自显式填写、外层继承或默认值。

对单标记的单值形式，C4 确定其唯一参数后，该值等同于该参数在当前标签中显式填写的值；因此它与写出该唯一参数名的具名形式具有相同的有效值、继承和注入语义。

```html
<shake : tense = 1.0>
    <shake : frequency = 0.05>...</shake>
</shake>
```

内层继承 `tense = 1.0`，并以 `frequency = 0.05` 覆盖该属性的默认值。

### S2. Scope 归一化

省略 `scope` 是 `scope = 0` 的语法糖。解析器必须将省略形式规范化为整数 `0`；它不表示“未指定 scope”，也不会创建匿名处理实例。

```html
<shake : tense = 1.0>...</shake>
```

等价于：

```html
<shake : tense = 1.0|scope = 0>...</shake>
```

### S3. 处理实例与生命周期

一个处理实例由实例键唯一确定：

    instance_key = (type, scope)

同一 `type` 且 scope 整数相同的标签必须使用同一个处理实例。不同 `type` 即使使用相同的 scope 整数，也必须使用不同处理实例。

解析器必须以整段文本收集全部不同的实例键，并为每个键生成恰好一个处理实例。实例从生成后持续存在，直至程序消亡；标签范围结束不得销毁它。实现可将默认实例（scope = 0）的生命周期绑定至管线组件、将具名 scope 实例绑定至单次解析；同一解析内每实例键仍恰对应一个实例。

```html
<type>...</type>
<type|scope = 0>...</type>
<type|scope = 1>...</type>
<type>...</type>
<type|scope = 1>...</type>
```

其中，省略 scope 的标签与 `scope = 0` 的标签共享实例；两个 `scope = 1` 标签也共享一个、但不同的实例。

### S4. 同实例嵌套与属性状态

当内层标签与外层标签具有相同实例键时，内层继承外层有效属性值；内层显式填写的属性覆盖继承值，未填写的属性保持继承值。退出内层后，属性状态必须恢复为外层有效值。

```html
<shake : tense = 1.0>
    <shake : tense = 1.5>...</shake>
    ...
</shake>
```

内层的有效 `tense` 为 `1.5`；退出内层后，外层范围内恢复为 `1.0`。

同一实例键的非嵌套块在属性语义上相互独立。前一个块结束后，其显式属性不得带入后一个块；后一个块应从自己的显式属性、适用外层值或默认值重新形成有效属性值。共享处理实例不表示共享标签属性环境。

嵌套标签实例键不同时，二者的属性状态互不继承也不覆盖。

### S5. 文本范围与标签收束

块标签的效果只作用于其内部文本，不作用于开始标签或结束标签的字符。

解析成功的标签字符必须收束：它们不得进入正式文本，也不得被任一标签效果处理。正式文本仅包含未被收束的内容字符。

### S6. 执行顺序

不同处理实例之间的正式执行顺序由 `TextPipeline` 配置决定。语言不规定全局默认顺序、不同标签类型的嵌套优先级，也不引入通用 `priority` 属性。

同一实例的嵌套仅按 S4 解释属性状态；该规则不表示不同处理实例之间具有固定执行先后关系。

### S7. 解析失败与放行

不满足 `Contextual Constraints.md` 或标签实现校验的候选标签，视为解析失败。解析失败不得创建标签节点、处理实例绑定或效果范围；其字符依 `Error Handling.md` 的 E4 按 HTML 风格在标签边界恢复。块结束标签依 E5 进行 HTML 风格的栈式结构恢复。

只有解析成功的标签字符才会依 S5 收束。单个标签解析失败不得中止整段文本的处理；实现可以记录诊断信息。
