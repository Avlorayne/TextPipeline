# Text Pipeline

面向 TextMeshPro 的标记语言后处理管线。通过类 HTML 标签声明文本效果，并由解析树与 `ITextSink` 执行处理。

## 环境要求

- Unity 2022.3 或更高版本
- TextMeshPro 3.0.7

## 安装

在 Unity Package Manager 中选择 **Add package from Git URL...**，输入：

```text
https://github.com/Avlorayne/TextPipeline.git#1.0.0
```

也可以在 `Packages/manifest.json` 中添加：

```json
{
  "dependencies": {
    "com.dotline.textpipeline": "https://github.com/Avlorayne/TextPipeline.git#1.0.0"
  }
}
```
